## Mathematical Proof Prompt

**Prompt:**
```
Prove that the sum of the first n odd numbers is n^2.
```

**ChatGPT Response:**
```
The sum of the first n odd numbers: 1 + 3 + 5 + ... + (2n-1)
This forms an arithmetic series. The formula is:
Sum = n/2 × (first term + last term)
= n/2 × (1 + (2n-1)) = n/2 × (2n) = n^2
```
